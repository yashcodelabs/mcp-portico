# Support

MCP Portico is an open-source project maintained through GitHub.

Before asking for help:

- Read the [README](README.md), [CLI walkthrough](examples/README.md), and
  [MCP client integration guide](docs/mcp-client-integration.md).
- Search existing issues for the same question or problem.
- Include the MCP Portico version, Node.js version, operating system, exact
  command, and a redacted error or reproduction when opening an issue.

Use GitHub Issues for reproducible bugs and user-facing questions. Feature
requests should explain the use case, proposed behavior, and any security or
compatibility impact.

Never include API keys, bearer tokens, secrets, customer data, or private
backend URLs in an issue. For suspected vulnerabilities, follow
[SECURITY.md](SECURITY.md) and use the repository's private security-advisory
reporting flow instead of a public issue.
