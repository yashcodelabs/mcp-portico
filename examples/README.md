# Examples

- `sample-catalog.json` - a compiled catalog v2 artifact (billing API) that
  passes `mcp-portico catalog validate`.
- `sample-overlay.json` - a policy overlay v1 that restricts and annotates
  operations during compilation.
- `sample-registry.json` - a registry v1 (JSON) with two tenants, principals,
  a shared global backend, and tenant-owned connections.
- `sample-registry.yaml` - the same registry in YAML.

OpenAPI specs and import fixtures land here in Phase 4.
